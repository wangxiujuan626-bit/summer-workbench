# Summer 工作台 Cola 连接插件

这个插件把工作台里经过确认的「今日经历卡」送进 Cola 的桌面主对话。

## 安装

1. 在 Cola 打开「技能 → 渠道 → 安装本地插件」。
2. 选择本目录 `cola-plugin`，不要选择 `dist` 子目录。
3. 安装并启动「Summer 工作台」。
4. 打开本机工作台后，点击「连接 Cola」。

这个目录里的 `dist/index.js` 已经包含插件运行所需的 SDK，粉丝解压后不需要再执行 `npm install` 或 `pnpm install`。

如果 Cola 提示“同名插件已安装”，说明电脑里还有旧版 `Summer 工作台`。先在「已安装」里卸载旧版，再重新安装这个 `cola-plugin` 文件夹；只需要更新旧版时做一次。

插件只监听本机 `127.0.0.1:43127`，只接受本机工作台 `127.0.0.1:8765` 或 `localhost:8765` 的请求。
工作台只会发送你在“结束今天”里确认过的经历卡，不会发送全部任务和工作台数据。

## 开发

```bash
pnpm install
pnpm build
```
