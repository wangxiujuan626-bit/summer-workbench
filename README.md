# Summer 工作台 Lite

一个纯本地的行动记录器：随手记、自动整理、每日复盘、手机与电脑同步，也可以按需连接 Cola 或其他 AI。

## 这个仓库就是公开入口

这是 Summer 工作台 Lite 的唯一公开 GitHub 仓库。粉丝直接在 GitHub 搜索“Summer 工作台 Lite”或“summer-workbench”，进入本仓库即可使用和查看源码，不需要向作者索取安装包，也不需要登录 Cloudflare。

- 最新可运行包就在仓库首页的 Summer工作台-Lite.zip。
- Summer工作台-Lite-纯本地开源源码.zip 是给开发者查看和修改的源码包。
- 不要下载 GitHub 自动生成的 Source code (zip) 来运行。

## 粉丝直接使用

在仓库文件列表点击 Summer工作台-Lite.zip，再点击下载按钮。解压后：

- macOS：双击 start.command。如果系统提示无法验证，右键它，选择“打开”，再选择“打开”。
- Windows：双击 start.bat。

浏览器会自动打开工作台。每个人第一次填写自己的昵称和头像，记录保存在自己的设备上，不会带入作者的个人数据。

如果要查看或修改源码，下载 Summer工作台-Lite-纯本地开源源码.zip；普通用户使用上面的运行包即可。

## 手机同步

电脑和手机连接同一个 Wi‑Fi：

1. 电脑打开工作台，点击“连接设备”。
2. 选择“这台已有内容”，生成二维码。
3. 手机扫码后直接进入电脑上的工作台。
4. 如果微信里不能添加到桌面，复制手机地址栏里的完整网址，必须包含 ?pair= 及后面的 6 位配对码，到 Safari 或 Chrome 打开。
5. 普通浏览器接入成功后，再点击“添加到手机桌面”。此时名字、头像和记录会保留。
6. 以后在任一设备点击“刷新”，同步两台设备的记录。

配对码有效 10 分钟。复制时漏掉 ?pair=，或超过有效期后，浏览器会被当成新设备；重新生成二维码即可。

## 可选连接 AI

工作台本身可以独立使用。需要时再安装同一个运行包里的：

- cola-plugin/：在 Cola 的“技能 → 渠道 → 安装本地插件”中选择这个文件夹。
- workbench-connector/：连接支持 MCP（模型上下文协议）的其他 AI 工具。

## 数据边界

这是纯本地版本，不依赖 Cloudflare，不需要云端账号。工作记录保存在运行工作台的电脑本地文件和各设备浏览器中，只在同一 Wi‑Fi 下按配对关系同步，不会自动上传到云端，也不会与其他人的数据混在一起。

## 开发者

需要 Node.js >=22.13.0 才能从源码重新打包：

npm install
npm run package:offline

源码修改和测试说明见项目目录中的 package.json 与 tests/。
